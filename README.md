# Module-TTRPG-with- All-AI
module buat main ttrpg kaya dnd dengan semua AI.
untuk memainkannya yang dibutuhkan adalah membuat project di AI yang ingin dijadikan Game Master bisa chatgpt, claude, grok, dll. sebagai contoh penulis memainkan dengan chatgpt free, dalam plan free hanya bisa mengupload 5 file dalam project maka yang diupload adalah gm guide v.3, big rule, ten shadows society, file story sebagai referensi, 10 jari shadow society. untuk memainkan story campaign baru shadow of the sealed hanya perlu buat chat baru di project tersebut masukan prompt yang ada di file major rule game master.docx. setelah menerima respon dari AI buat perjanjian dengan game master(AI) yang berisikan file battle rule mana yang ingin di apply di campaign ini. dalam perjanjian yang dibuat antara gm dan player memuat battle rule, adjustment story jika ingin ganti karakter, genre, dan memainkan arc berapa. penulis merekomendasikan setiap dalam satu chat mainkan 1 arc aja, untuk arc berikutnya new chat di project dengan membuat file handover. dalam memainkannya biasanya penulis membuat 2 file yaitu file inventory dan note player. note player berisikan catatan player dalam memainkan karakter sebgai cara kerja kenapa player memilih ini atau sebagai ingatan dalam kepala karakter. file tersebut tidak perlu di upload namun dalam setiap kelar 1 session biasanya player mengirim note player itu ke gm untuk mengingat atau membahas hal tersebut sebagai behind the scene. dalam 1 session minta game master(AI) buat kasih parameternya yaitu beberapa event yang bisa mengarah ke milestone cerita atau flex module.
